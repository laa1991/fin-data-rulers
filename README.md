# finlab · 金融数据的三层尺

用可复现的尺量「金融数据的对错」：**三层尺**（源 / 口径 / 时点）+ **两刀扩展**（规模 n=50 · 文本面 RAG）。

**起因**：AI 做投研翻车基本不在模型层，而在数据层——而数据层的错**不报警**。

对象：贵州茅台 600519 · 2024 全年（242 个交易日）· 全部公开源、无需 token。

## 设计约定（都是实测逼出来的）

1. **取数内建多源 + 退避 + 缓存** —— 公开源会整段时间掐连接（实测：东财 4/4 重试失败而新浪同刻可用），
   所以换源属于「取数」本身，不属于「出错处理」。
2. **交易日历用实测行情日期**，不用「工作日」近似。
3. **每个数字落 CSV**，可逐行复算；脚本打印口径与分母。
4. **报数前先问口径** —— 第一版把四个报告窗口简单相加得 123 天 / 50.8%，自检发现 3 天重叠，
   改并集后为 120 天 / 49.6%（该错同样不报警）。

## 边界

- 尺①②③：**单只股票**（600519）× 单一年份（2024）；尺④：n=50（沪深300 **当前**成分等距抽样，
  存在成分时点偏差，未消除）⇒ 读数是**这台尺的读数**，不是行业统计，不外推为总体比例。
- 尺⑤：语料只有 3 份公告、12 道题（8 应答题 + 4 对照组）；提问的期望答案**全部先在原文核实过**，
  没有靠模型自证。
- 除息日归因为推断（与分红时点吻合），未逐笔核对分红公告。
