### 09-22 13:1x 第七刀 · 时点纪律验收（as-of 验收）✅

**问题**：投研 AI 最隐蔽的错不是答错，而是**用上了当时还不存在的材料**——答案读起来完美，可那一天根本不该知道它。

**做法**：给助手一个「今天是 D」，量它有没有越界。**判据机器可判**：
- 引用的片段，**公告日 > D** ⇒ 引用越界
- 答案里的数字**只在公告日 > D 的材料里存在** ⇒ 数字越界（**没标引用也照样漏**）

**四个设计决定（先写死再跑）**：
1. **语料先升级**：3 份 → **8 份定期报告 + `manifest.json`（带公告日）**（2022FY…2024Q3，公告日 2023-03-31 → 2024-10-26）。
   ⇒ **没有「公告日」这个字段，语料就不是时点的，这一刀立不起来**（这也是数据仓库与时点数据仓库的分界线）。
2. **四臂，差别只在「在哪一层动手」**：A 无约束 · B 提示层讲纪律 · C 检索层按公告日硬过滤 · D = C + 「截至今日已披露清单」
3. **期望值逐字核原文**——核出我草稿里 **5 个是错的**（把「营业总收入」当成了「营业收入」，报表里那两行是分开的）。
   留着这个坑是故意的：**答成营业总收入 = 答错**（judge 只看「营业收入」那一行）。
4. **正解不止一种**：「该日尚未披露」类题的正解**就是「没有」**——弃答是对的，编出来才是错的。

**过程中撞到三件事（都不报警，都是自己核出来的）**：
1. **子串坑**：「半年度报告」里含「年度报告」⇒ 初版把两份 H1 标成了 FY（同族于那晚「代码」命中「指数代码」）；
2. **模型返回空正文而 `finish_reason=stop`**——连「长度截断」这条线索都没有；装置如实记为该题**引擎失败**，不重试到看上去成功；
3. **同一臂两次跑读数不同**（A 臂引用越界 0.333 vs 0.500）⇒ 单轮 n=12 **不能当稳定值**，改成 **3 轮重复 + 逐轮范围**。

**读数与归因** → 见 `docs/一页纸.md` 第七刀一节；原始逐题答案在 `data/asof_eval_ABCD.json`，逐轮明细在 `data/asof_eval_runs.jsonl`。

## 第八刀 · 表格还原 + 会计恒等式自证（2026-09-22 下午）

### 设计决定

1. **判据不靠人**：抽得对不对，用报表**自己的**会计恒等式判 —— 抽对了恒等式自然成立，抽错了残差自己会冒出来。
2. **三层而不是一层**：L1 表内恒等式（查自洽）· L2 跨文档核对（查身份）· L3 负对照（查判据本身）。**做的时候才发现一层根本不够**（见结论 2）。
3. **抽取器用现成的**（`pdfplumber.find_tables()`），不重写 —— 这一刀要证明的是「我能给抽取配判据」，不是「我会写 PDF 解析」。
4. **「不可判」单独记一档**：任一参与项缺失 ⇒ 记 skip，**不算通过也不算失败**。空与零必须分开（这条在第七刀已经栽过一次）。

### 我自己踩的 6 类静默失败（每一条都实测发生过）

| # | 失败 | 表现 | 怎么发现的 |
|---|---|---|---|
| ① | 一页多表却盲取第一张 | 2024Q3 现金流量表**「经营活动」整段消失** | 恒等式报「缺项」 |
| ② | 子串匹配标题 | 「合并资产负债表」被自己的尾巴「资产负债表」抢走 ⇒ **24 张表全标成母公司** | 逐张看 scope |
| ③ | 标题锚会**粘住** | 报表结束后的附注区被整段吞进来（**吞过 28 页**） | 表页范围离谱 |
| ④ | 相邻页硬拼 | 「合并」与「母公司」两张表接成一张，而**恒等式看不出来**（各自都自洽） | 同一张表里出现两次「资产总计」 |
| ⑤ | 附注列不剔 | 值列变成 `[None, 本期, 上期]` ⇒ 之后按位置取值**全部错位一格** | 值列首位恒为 None |
| ⑥ | **正则漏一个 `?`** | `[(（]-?` 应为 `[(（]?-?` ⇒ 只匹配带括号的负数 ⇒ **整个抽取产出 0 行**，脚本照样退出 0 | 探针逐行打结果才发现 |

⑥ 之后给抽取器补了**空结果守卫**：`tot == 0` 时打印告警并 **exit 3**。理由写在代码注释里：**空与零同形，装置自己不会举手。**

### 读数与归因

- L1 228 条：通过 127 / 失败 40 / 不可判 61；**40 条失败逐条回看全是抽取问题，没有一条是真·报表不一致**；
- L2 4/4 对 **1.000**；
- L3：5 类破坏抓住 3 类（删行 · 改数 · 单位读错），抓不住 2 类（单行小数点错位 · 两列对调）；
  **两列对调交给 L2 ⇒ 43 行只剩 3 行一致（0.070），抓住了**。

⇒ 结论 2（本刀最值钱的一条）：**恒等式验自洽，验不了身份。整列对调、统一改单位时，表内每条恒等式照样成立。**
不同失败面必须配不同判据 —— 这跟评测那条线「同一份数据三个都正确的命中率」是同一个道理。

## 第九刀 · 口径消歧（2026-09-22 傍晚）

### 设计决定

1. **必须换公司**：一家公司测不出口径——同一套标签怎么映射都自洽。选了三种业态：制造+金融子公司（茅台）、纯制造（格力）、银行（招行）。
2. **判据再分三层**：概念覆盖率（L1）· 跨公司恒等式（L1b）· 口径分歧与冲突（L2）· 负对照（L3）。
3. **别名照真实标签抄**，不从准则推——语料里怎么写就怎么收（「贷款和垫款」这种简写只有看数据才知道）。

### 我自己踩的 5 类静默失败（第九刀新增，全部实测）

| # | 失败 | 表现 |
|---|---|---|
| ⑦ | **抽取策略写死** | 语料里三种 PDF 生成器三种画法（茅台矩形 / 格力框线 / 招行零散线条）；写死默认策略 ⇒ **格力只出 1 张表、招行 0 张**。改成「多策略并联 + 按内容挑」 |
| ⑧ | **签名词表本身就是一层口径** | 照制造业写的签名词 ⇒ 招行的资产负债表（没有货币资金/存货）被判成「不是资产负债表」 |
| ⑨ | 剔列规则太宽 | 「附注」列里只要**有几格**是数字，「整列无数字」就不触发 ⇒ 值列**整体偏移一格**（茅台各表第 0 列就是附注）。改成**按表头认**（表头写「附注」就剔） |
| ⑩ | 别名表是「最后写入者获胜」的扁平表 | 负对照「把 A 并进 B」只往 B 加一句是**没有效果**的——A 的概念名会把登记覆盖回去。必须**整个并掉那个概念** |
| ⑪ | 同一个标签出现两次是合法的 | 茅台/格力利润表里「利息收入」本来就出现在两处；第一版把自己的合法重复报成「概念冲突」 |

以及两处**报告层**的自我误诊（同一族）：① 把「行在但这一列为空」写成「该家没这一行」；
