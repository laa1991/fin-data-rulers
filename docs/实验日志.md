**判据（全部预先登记）**：

| # | 判据 | 通过线 | 谁在看 |
|---|---|---|---|
| ① | 判对率（强标志判对/有表格子） | **不低于 20/25（80%）** | bench 复算 |
| ② | 「不拼」开火次数 | **下降**（基线 14 次） | extract 日志计数 |
| ③ | 三表格子数 | **不低于 27/33** | bench 复算 |

| ⑤ | 对比表 ✓ 格数 | **不低于 26** | compare.json 计数 |

**回退线（任一触发即回退整刀）**：① 判对率下降 · ④ 出现任何新的恒等式失败 · ⑤ ✓ 格数下降 —— 三者任一 ⇒ **回退**，并把前后读数都写进本节（**净效果为负的改动不回退，等于自己造假**）。

**什么算「无效应」**：判对率与三表格子都不动、开火次数也不降 ⇒ 记为**无效应**，如实写，不硬说成改进（今天已有三次「+1 格但开火不动」的先例）。

**已知不能碰的**：招行那类表的**列集本身**若来自「纯文本对齐」策略的伪列（页眉文字被当列），裁页眉**只能去掉第一行**、去不掉那些列 ⇒ 这一刀**可能只治一半**。预注册时就写明：**若开火次数不降，结论就是「页眉带不是根因」，而不是"再裁多一点"**。

**产出**：十一家的对比表，**99 格 · ✓ 26 / ⚠ 26 / ? 47**，状态里合并进**表级可信度**（强标志行 / 恒等式 / 单位）。

### 教训 ㉔ · 「按表头认列」的前提是**表头真的是表头**

`col_for_period` 写着「按表头日期认列，不按位置猜」——**只在表头是真表头时成立**。实测格力的表头是**页眉文字**
（`['', '珠海', '格力电器股份有限公司2023年年度', '报告全文', '']`），而「2023年」正好在**公司名**里
⇒ 索引算成 1 ⇒ **读到 2022 的值**（3,550.71 亿，真值 3,680.54 亿），**量级正常、状态仍然是 ✓**。
⇒ 修：值列里 **≥2 格带日期**才认那个表头，否则退回第 0 列。修后与真值一致。

### 教训 ㉕ · 单位识别**不能要求冒号**

中国平安写的是「除特别注明外，金额单位**为**人民币百万元」——**没有冒号**；而正则写成 `单位[:：]` ⇒ **静默失配**
⇒ 那一家的**所有数量级差 100 万倍**（`109,274` 而非 `109,274,000,000`），**而状态照样是 ✓**。
⇒ 修：`单位\s*[:：为是]?`。修后平安净利润与真值一致（1,092.74 亿）✓，状态分布 ✓23/⚠29 → **✓26/⚠26**。

### 一句话

**一个字符级的前提（下标、冒号）静默不成立，数值就错，而状态不会红。**
今天同一个形状出现了五次（跨页列宽 / 附注列 / 页眉当列 / 表头索引 / 单位冒号）——**每次都是"我以为的那个字段/分隔符一定在"。**

### 09-22 13:1x 第七刀 · 时点纪律验收（as-of 验收）✅

**问题**：投研 AI 最隐蔽的错不是答错，而是**用上了当时还不存在的材料**——答案读起来完美，可那一天根本不该知道它。

**做法**：给助手一个「今天是 D」，量它有没有越界。**判据机器可判**：
- 引用的片段，**公告日 > D** ⇒ 引用越界
- 答案里的数字**只在公告日 > D 的材料里存在** ⇒ 数字越界（**没标引用也照样漏**）

**四个设计决定（先写死再跑）**：
1. **语料先升级**：3 份 → **8 份定期报告 + `manifest.json`（带公告日）**（2022FY…2024Q3，公告日 2023-03-31 → 2024-10-26）。
   ⇒ **没有「公告日」这个字段，语料就不是时点的，这一刀立不起来**（这也是数据仓库与时点数据仓库的分界线）。
2. **四臂，差别只在「在哪一层动手」**：A 无约束 · B 提示层讲纪律 · C 检索层按公告日硬过滤 · D = C + 「截至今日已披露清单」
3. **期望值逐字核原文**——核出我草稿里 **5 个是错的**（把「营业总收入」当成了「营业收入」，报表里那两行是分开的）。
   留着这个坑是故意的：**答成营业总收入 = 答错**（judge 只看「营业收入」那一行）。
4. **正解不止一种**：「该日尚未披露」类题的正解**就是「没有」**——弃答是对的，编出来才是错的。

**过程中撞到三件事（都不报警，都是自己核出来的）**：
1. **子串坑**：「半年度报告」里含「年度报告」⇒ 初版把两份 H1 标成了 FY（同族于那晚「代码」命中「指数代码」）；
2. **模型返回空正文而 `finish_reason=stop`**——连「长度截断」这条线索都没有；装置如实记为该题**引擎失败**，不重试到看上去成功；
3. **同一臂两次跑读数不同**（A 臂引用越界 0.333 vs 0.500）⇒ 单轮 n=12 **不能当稳定值**，改成 **3 轮重复 + 逐轮范围**。

## 第八刀 · 表格还原 + 会计恒等式自证（2026-09-22 下午）

### 设计决定

1. **判据不靠人**：抽得对不对，用报表**自己的**会计恒等式判 —— 抽对了恒等式自然成立，抽错了残差自己会冒出来。
2. **三层而不是一层**：L1 表内恒等式（查自洽）· L2 跨文档核对（查身份）· L3 负对照（查判据本身）。**做的时候才发现一层根本不够**（见结论 2）。
3. **抽取器用现成的**（`pdfplumber.find_tables()`），不重写 —— 这一刀要证明的是「我能给抽取配判据」，不是「我会写 PDF 解析」。
4. **「不可判」单独记一档**：任一参与项缺失 ⇒ 记 skip，**不算通过也不算失败**。空与零必须分开（这条在第七刀已经栽过一次）。

| ④ | 相邻页硬拼 | 「合并」与「母公司」两张表接成一张，而**恒等式看不出来**（各自都自洽） | 同一张表里出现两次「资产总计」 |
| ⑤ | 附注列不剔 | 值列变成 `[None, 本期, 上期]` ⇒ 之后按位置取值**全部错位一格** | 值列首位恒为 None |
| ⑥ | **正则漏一个 `?`** | `[(（]-?` 应为 `[(（]?-?` ⇒ 只匹配带括号的负数 ⇒ **整个抽取产出 0 行**，脚本照样退出 0 | 探针逐行打结果才发现 |

⑥ 之后给抽取器补了**空结果守卫**：`tot == 0` 时打印告警并 **exit 3**。理由写在代码注释里：**空与零同形，装置自己不会举手。**

### 读数与归因

- L1 228 条：通过 127 / 失败 40 / 不可判 61；**40 条失败逐条回看全是抽取问题，没有一条是真·报表不一致**；
- L2 4/4 对 **1.000**；
- L3：5 类破坏抓住 3 类（删行 · 改数 · 单位读错），抓不住 2 类（单行小数点错位 · 两列对调）；
  **两列对调交给 L2 ⇒ 43 行只剩 3 行一致（0.070），抓住了**。

⇒ 结论 2（本刀最值钱的一条）：**恒等式验自洽，验不了身份。整列对调、统一改单位时，表内每条恒等式照样成立。**
不同失败面必须配不同判据 —— 这跟评测那条线「同一份数据三个都正确的命中率」是同一个道理。

**细节** → `docs/一页纸.md` 第八刀一节；结构化落盘 `data/tables/`（40 个 JSON）；判据明细 `data/table_verify.json`。

## 第九刀 · 口径消歧（2026-09-22 傍晚）

### 设计决定

1. **必须换公司**：一家公司测不出口径——同一套标签怎么映射都自洽。选了三种业态：制造+金融子公司（茅台）、纯制造（格力）、银行（招行）。
2. **判据再分三层**：概念覆盖率（L1）· 跨公司恒等式（L1b）· 口径分歧与冲突（L2）· 负对照（L3）。
3. **别名照真实标签抄**，不从准则推——语料里怎么写就怎么收（「贷款和垫款」这种简写只有看数据才知道）。

### 我自己踩的 5 类静默失败（第九刀新增，全部实测）

| # | 失败 | 表现 |
|---|---|---|
| ⑦ | **抽取策略写死** | 语料里三种 PDF 生成器三种画法（茅台矩形 / 格力框线 / 招行零散线条）；写死默认策略 ⇒ **格力只出 1 张表、招行 0 张**。改成「多策略并联 + 按内容挑」 |
| ⑧ | **签名词表本身就是一层口径** | 照制造业写的签名词 ⇒ 招行的资产负债表（没有货币资金/存货）被判成「不是资产负债表」 |
| ⑨ | 剔列规则太宽 | 「附注」列里只要**有几格**是数字，「整列无数字」就不触发 ⇒ 值列**整体偏移一格**（茅台各表第 0 列就是附注）。改成**按表头认**（表头写「附注」就剔） |
| ⑩ | 别名表是「最后写入者获胜」的扁平表 | 负对照「把 A 并进 B」只往 B 加一句是**没有效果**的——A 的概念名会把登记覆盖回去。必须**整个并掉那个概念** |
| ⑪ | 同一个标签出现两次是合法的 | 茅台/格力利润表里「利息收入」本来就出现在两处；第一版把自己的合法重复报成「概念冲突」 |

以及两处**报告层**的自我误诊（同一族）：① 把「行在但这一列为空」写成「该家没这一行」；
② 抽取器语法崩掉后判官照样「跑完」并报满屏 0 —— 之后给判官补了**空表守卫（非零退出）**。

### 读数与归因

- L1 覆盖率：格力 BS **15/15** · 茅台 10/15（缺的是**抽取漏页**）· 招行 6/15（缺的是**业态不同**）
- L1b 跨公司恒等式 **27 条可判 · 通过 27 · 失败 0**
- L2 口径分歧 **11 个概念**（标签不同）· 概念被两行占用 0
- L2b/L2c：茅台 净利率 **49.64% vs 50.60%（差 0.96 个百分点）**、格力 14.15% vs 14.23%
- L3 负对照 **3/3 全被抓住**（张冠李戴 / 同名不同物 / 同物不同名）

## 第十刀 · 从原始公告到一张可复算的同业对比表（2026-09-22）

### 设计决定

1. **要给的是产物，不是方法**：前九刀全是「量某个面」，这一刀把概念映射 + 恒等式 + 抽取覆盖串成一条命令，出一张表。
2. **每一格必须自报可信度**：`✓ 可用` / `⚠ 抽取缺口` / `? 未命中`。**「不可用」不许写成 0**（空与零同形的老账）。
3. **原单位一路留到产物里**：换算到元是为了可比，标注原单位是为了让人知道这不是表里本来的样子。

### 本刀新增的三条教训

| # | 教训 | 细节 |
|---|---|---|
| ⑫ | **单位是隐性口径，而且不报警** | 茅台/格力是元，**招行是百万元**。不换算 ⇒ 招行 11,028,483 看着是茅台的 1/25000，**实际是它的 40 倍**。数字在、格式对、量级错。单位识别的兜底还得往前翻页（单位行常写在没被纳入本表的首页） |
| ⑬ | **一页两表的切分**：报表首页常同时有上一张表的尾巴和下一张表的头 | 茅台 p61 = 合并表的权益段 + 母公司表的开头。试过「一页多张全取」⇒ **无改善且总行数反而降**，已回退；**不保留对自己没用的改动** |
| ⑭ | 列偏移的第二种成因：**表头是页眉文字**时认不出「附注」 | 招行的表头第一格是「招商银行股份有限公司 第八章 财务报告」，按表头剔列失效 ⇒ 改成**优先按表头 + 兜底按「多数行为空」**，两条一起用 |

### 读数

- 27 格：**✓ 20 · ⚠ 4 · ? 3**（起始读数 ✓16 / ⚠7 / ?4，修完单位与列偏移后改善）
- 抽查自洽：茅台 49.04B + 223.66B = 272.70B ✓ · 格力 247.41 + 120.65 = 368.05 ✓ · 招行资产负债率 90.16%（银行该有量级）✓
- 剩余 7 格全部是**判据判出来的不可用**，逐格有原因（茅台权益段与母公司表同页；招行标签与列结构不同）

## 第十一刀 · 十一家不同业态：把「可能翻车」变成读数（2026-09-22）

### 起因

一页纸的「诚实边界」里我写着「**换一批公司仍可能翻车**」——**没测过**。同一份材料要求别人每个数字可复算，
自己放一句没测过的话就是双标。⇒ 把语料从 3 家扩到 11 家，量出来。

### 读数

| 指标 | 值 |
|---|---|
| 三表抽到 | **23/33**（招行 / 神华 / 中石油 = 0/3） |
| 概念命中 | **148/281 = 52.7%** |
| 恒等式 | 通过 **23** · 失败 **0** · 不可判 **39** |
| 对照 | 被调过的茅台/格力/伊利 **29–34/36** · 没见过的 8 家 **1–15/36** |

### 失败模式（诊断过，不是猜的）

| # | 模式 | 证据 |
|---|---|---|
| ① | **表检不出** | 神华 p123/124 有「合并/母公司资产负债表」标题，四条策略**零候选** —— 无边框、靠缩进对齐的排版 |
| ② | **范围判错** | 招行 p132 检出 **95 行**的表，却被归到母公司 ⇒ 合并键缺位 ⇒ 三表按 0 计 |

### 本刀新增的三条教训

| # | 教训 | 细节 |
|---|---|---|
| ⑮ | **取数层也会静默取错** | 中信证券抓到的第一份是**别家券商出的《…2023年度持续督导工作报告》**（0.39 MB）——文件下得来、PDF 打得开，**只是内容根本不是年报**。修法：标题**末尾**必须是「年度报告」+ DROP 加 督导/关于 + **大小守卫（<1.5 MB 不收）** |
| ⑯ | **同一份事实两个家必然漂移** | 公司清单在 `coa_fetch` 与 `coa_map` 各有一份 ⇒ 扩到十一家后**度量只认了 3 家**（表也只出 3 家）。改成 `from coa_fetch import COMPANIES` 单一来源 |
| ⑰ | **看进度要看副作用，不要看回话** | 后台作业输出被管进 `Select-Object -Last 60` ⇒ **缓冲到整条管道结束才吐字** ⇒ 644 秒"零输出"看着像卡死，而盘上已落 **6 家 / 57 张表** |

### 一句话

**判据判出来的每一个问题，最后都追到我自己头上**（恒等式零失败、39 条全不可判）——
这条在第八刀出现过一次，扩到十一家后**再次成立**。

### 附 · 修两个失败模式（同日）

**修法**：① 标题必须**独立成行的短标题**（`is_heading`：去行首编号后必须以标题开头，尾巴只允许「（续）」这类）
② **每张候选表按它上方最近的标题定范围**（`page_headings` 用词坐标重建行，拿到 y）。

| 指标 | 修前 | 修后 |
|---|---|---|
| 有表家数 | 8/11 | **10/11** |
| 三表抽到 | 23/33 | **31/33** |
| 概念命中（绝对 / 比率） | 148 / 52.7%（分母 281） | 165 / 45.0%（**分母 367**） |
| 恒等式 | 通过 23 · 失败 0 · 不可判 39 | 通过 22 · 失败 0 · 不可判 60 |

**不是纯赢**：正对照茅台 29/36 → **23/36**、伊利 34/36 → **27/36** 回退 ⇒ 修 A 家会伤 B 家。

### 教训 ⑱ · 覆盖式重写 = 语料静默缩水

`coa_fetch` 重跑时用**「本次成功的那几家」重写 manifest** ⇒ 我收紧标题过滤那一次，
语料从 **11 家悄悄变成 8 家**（招行 / 神华 / 中石油被删），而**后面所有读数照算、度量层完全看不出来**。
修法：读旧账 + 按 symbol 合并 + 匹配不上就**沿用盘上的旧件** + **大声说出来**。
⇒ 同族于「账只能增改、不许覆盖」；也同族于 **报告层把「语料少了几家」写成了「这几家没有表」**。

### 教训 ⑲ · 报比率必须同时报分母

同一个装置的前后两版：概念命中**绝对数 148 → 165（涨）**、**比率 52.7% → 45.0%（跌）**，
因为**能判的格子从 281 涨到 367**（有表的公司 8 → 10 家）。**只看比率会得出与事实相反的结论。**

### 附二 · 选错表（噪音惩罚 + 硬闸）

**诊断**：低覆盖率主要**不是缺别名**，是**选错表** —— 11 家里 9 家的现金流量表格子被
「分部报告 / 权益变动表 / 费用明细 / 收入分解附注」占住过（它们也含「营业收入」「净利润」这些词）。

**改法**：① 打分加**噪音惩罚**（分部/附注/关联交易/增减变动… 各 −2）
② **硬闸**：该格必须至少有一条**它自己该有的强标志行**，**否则宁可不填**。

| 指标 | 加闸前 | 加闸后 |
|---|---|---|
| 强标志判**对**的格子 | 16/31 | **21/28** |
| 其中现金流量表 | **2/11** | **6/11** |
| 概念命中 | 165/367 | 152/330 |
| 恒等式 | 通过 22 · 失败 0 · 不可判 60 | 通过 13 · **失败 1** · 不可判 56 |

⇒ **精度换召回，两头都报**：对的格子 +5，代价是 3 格被正确置空。

### 教训 ⑳ · 多页拼接没人校验「各页列含义是否一致」（这条是判据自己抓出来的）

加闸后出现**整条线的第一条恒等式失败**：伊利 CF「净增加额 = 经营 + 投资 + 筹资 + 汇率影响」，
残差 **4,870,037,070.20**。追因：我取到的「经营活动净额」= **13,420,320,580.36**（**2022 年的列**），
而原文 2023 年是 **18,290,357,650.56**。该行在 **p91**、其余在 **p92** ⇒ **两页的列映射不一致，没有任何东西在管**。

**残差 = 18,290,357,650.56 − 13,420,320,580.36，分毫不差** ⇒ **判据不只说"这里错了"，它指着那一行。**
所有数字都看着像真的（量级对、格式对），**只有这条判据能让它现形**。
⇒ 待修：拼接多页时按**表头**归一对齐列（现在只按页邻接拼），并对每个合并表跑一次「列一致性」自检。

### 教训 ㉑ · 标题表只有裸名 ⇒「母公司X表」整页被并入「合并」

`is_heading` 要求标题在**行首**，而标题表里只有裸名（资产负债表 / 利润表 / 现金流量表）⇒
「**母公司**现金流量表」这一行**一个都匹配不上**，于是该页沿用上一个锚（合并）⇒ **母公司的事被记进合并**。
实测：伊利 p93（母公司现金流量表）的「经营活动净额 8.43e9」被当成了合并的数。
⇒ 修：标题表补「母公司+表名」「本公司+表名」显式变体。**裸名规则遇到前缀词就静默失效**。

### 教训 ㉒ · 主段按行数挑 ⇒「续表页」压过正文页

伊利合并 CF 被列守卫拆成两段（p91 正文 26 行 / p92 续表 30 行），按行数取把**续表当正文**，
而含「经营活动净额」的正文页被降级成碎片 ⇒ 表里**没有那一行**。
⇒ 修：主段优先序改成 **先看有没有该表的强标志行，再看行数**。
⇒ 同族于「按长度/大小挑代表」的一切地方：**长度不是内容的代理**。

### 教训 ㉓ · 试过「按表头归一到本期列再拼」—— 失败并回退

想把「列宽不一致就不拼」升级成「归一到本期列再拼」（既不失真也不丢行）。**实测产出错值**：
伊利 CF「经营活动净额」变成 **8,434,869,082.25**（既非 2023 的 18.29e9、也非 2022 的 13.42e9），且出现两行同名。
根因：归一的前提是「**表头格数 = 行宽 + 1**」，而我的表头可能来自**上一页**或**表头修复路径** ⇒ 索引不可信。
⇒ **回退**。判据：**会产出错值的版本比缺值更坏**（错的不报警、缺的会进「不可判」）。
⇒ 正解（下次）：先按**内容**剔附注列（全为小整数/空）让宽度天然一致，再谈归一。
